# CopyButton

Copies a value (your email) to the clipboard and swaps its label to "Copied" for two seconds, with a small `paper-raised` toast showing the value. Provide `value`; `label`, `copiedLabel`, `variant` (default `text`) and `showValue` are optional.

- Pair it with the solid "Say hello" button, because mail links don't open for everyone.
- The toast says what was copied, never that a message was sent.
