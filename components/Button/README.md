# Button

Three variants. **solid** (`ink` fill, `on-ink` text) at most once per view, for the one thing the page is for, usually "Say hello". **ghost** (default) has a `line-strong` border. **text** is a quiet label that turns `ink` on hover. Pass `href` to render a link styled as a button.

- Verb first, sentence case, two words or fewer: "Say hello", "Copy email", "Resume".
- Height 36px, `radius-sm`, `label` type. Focus shows `focus-ring`.
- Don't use marigold fills, icons-only buttons, or more than three buttons in a row.
