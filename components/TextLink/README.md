# TextLink

An inline link that reads as text: `link` colour (`ink`) with a 1px `line-strong` underline offset 3px, turning `ink` on hover. Provide `href` and the words; links starting with http(s) are treated as external and get a thin `↗` and a new tab, or set `external` yourself.

- Link the noun, not "here" or "click".
- Don't colour links marigold or bold them. The underline is the only signal.
