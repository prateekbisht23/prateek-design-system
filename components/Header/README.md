# Header

Name on the left, three or four plain-text nav links on the right, one `line` hairline below. Provide `name`, `homeHref` and `links` (`{label, href, active}`); mark the current page `active` so it reads in `ink` while the rest stay `ink-muted`.

- Do: keep labels to one word, sentence case ("Work", "Notes", "About", "Contact").
- Do: put it inside the `column` wrapper so it lines up with the content.
- Don't: add icons, a logo image, a theme toggle or a CTA button here. If the links stop fitting on one line, cut a link before adding a menu.
