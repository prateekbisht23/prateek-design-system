# Status

The "Now ·" line under the name, led by the marigold dot. Provide the sentence as `children`; `label` defaults to "Now". `live` (default true) adds a soft pulse, which stops under reduced motion.

- One per page, directly under the name. It is the only marigold on the screen.
- Name one concrete thing, with a date if there is one: "Shipping weighted routing, Nov 2026".
- Don't stack several statuses or use it for notifications.
